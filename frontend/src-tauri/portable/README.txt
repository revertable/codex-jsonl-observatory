Codex Session Observatory - Portable Windows Build
================================================

English
-------

Extract the ZIP archive first, then run codex-session-observatory.exe.

This app reads local Codex session JSONL files selected by the user. Supported
session sources include Codex CLI and the Codex Windows app.

Export Worklog writes generated worklog bundles to a user-selected folder.
Exported worklogs may contain prompts, local paths, command output, code
snippets, and project-specific details. Review exported worklogs before
sharing them.

Security and authenticity
-------------------------

This build is not code-signed, so Windows SmartScreen may show an
unknown-publisher or unrecognized-app warning.

Official releases:

https://github.com/revertable/codex-session-observatory/releases


한국어
------

먼저 ZIP 압축을 푼 다음 codex-session-observatory.exe를 실행하세요.

이 앱은 사용자가 선택한 로컬 Codex 세션 JSONL 파일을 읽습니다. Codex CLI와
Codex Windows 앱에서 생성된 세션을 지원합니다.

Export Worklog는 생성된 작업 로그 번들을 사용자가 선택한 폴더에 저장합니다.
내보낸 작업 로그에는 프롬프트, 로컬 경로, 명령 출력, 코드 조각 및 프로젝트별
정보가 포함될 수 있습니다. 공유하기 전에 내보낸 내용을 검토하세요.

보안 및 파일 출처 안내
----------------------

이 빌드에는 코드 서명이 없으므로 Windows SmartScreen에 게시자를 알 수 없거나
인식되지 않은 앱이라는 경고가 표시될 수 있습니다.

공식 릴리스:

https://github.com/revertable/codex-session-observatory/releases
